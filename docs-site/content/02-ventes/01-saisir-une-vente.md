## Où trouver cet écran

Menu **Gestion des ventes → Ajout manuel des ventes**.

Deux façons de saisir sont proposées — choisissez celle qui correspond à votre situation.

## Mode "Par tickets" — pour saisir chaque vente séparément

C'est le mode à utiliser pour saisir des ventes une par une, comme des vrais tickets de caisse.

1. Sur l'écran de saisie, choisissez la carte **Par tickets**.
2. Pour le premier ticket, renseignez :
   - Le **service** (sur place / à emporter).
   - Le **mode de règlement** (espèces, carte bancaire, chèque, ticket restaurant...).
   - Les **articles vendus** : cherchez le produit, choisissez sa variante et ses extras si
     besoin, indiquez la quantité.
3. Cliquez sur **Ajouter un ticket** pour saisir un deuxième ticket — un nouveau formulaire vide
   apparaît, le premier reste enregistré dans la liste au-dessus. Répétez autant de fois que
   nécessaire.
4. Une fois tous les tickets saisis, vérifiez le récapitulatif puis confirmez l'enregistrement.

> 📸 **Capture d'écran à ajouter :** mode "Par tickets", avec un ticket rempli et le bouton
> "Ajouter un ticket" mis en évidence.

> **Astuce.** C'est le même principe utilisé ailleurs dans l'application partout où vous pouvez
> ajouter plusieurs éléments d'un coup (par exemple pour ajouter plusieurs ingrédients en même
> temps dans **Stock → Inventaires**) : un bouton "Ajouter…" qui ouvre un nouveau formulaire vide
> à chaque clic.

## Mode "Par quantités vendues" — pratique pour une journée entière

Plutôt que de recréer chaque ticket, indiquez simplement combien d'unités de chaque produit ont
été vendues sur la période, puis vérifiez que le total encaissé (espèces + carte + autres modes)
correspond bien à ce qui a été réellement compté en caisse.

1. Choisissez la carte **Par quantités vendues**.
2. Pour chaque produit vendu, indiquez la quantité.
3. Renseignez la répartition du règlement (combien en espèces, combien par carte, etc.).
4. Vérifiez que le total correspond, puis confirmez.

## Importer des ventes depuis un fichier

Si vous avez déjà les ventes dans un fichier Excel ou CSV (par exemple exporté d'une caisse
enregistreuse), utilisez plutôt **Gestion des ventes → Import Excel/CSV** — voir
[Importer des ventes depuis un fichier Excel/CSV](/importer-des-ventes).

## Rembourser une vente

Si une vente a été saisie par erreur ou doit être annulée, ne la supprimez pas — utilisez le
remboursement, qui réintègre automatiquement le stock consommé et annule les effets comptables de
la vente. Voir [Rembourser une vente](/rembourser-une-vente).
